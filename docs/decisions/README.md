# Architecture Decision Records

Ambiguous design calls get a short ADR here — one file per decision,
numbered and dated, stating the problem, the decision, and its consequences.
An ADR is also the only way to revise `PHILOSOPHY.md`: a change that conflicts
with a tenet is wrong until the tenet is deliberately revised by an ADR, never
worked around silently.

Keep them short. Don't block work on them.
